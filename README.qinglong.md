# 旧版青龙面板部署教程

> **旧版 `autosignin.py` 仅为青龙面板兼容而保留，后续不再维护。建议迁移到 [单机部署](README.md)。**

本教程根据迁移前的 [README](https://github.com/AkiyaKiko/EhentaiAutoSignIn/blob/edc7016/README.md) 提取，并结合保留的脚本补充说明。

## 1. 安装依赖

在青龙面板的依赖管理中添加以下 Python 依赖：

```text
bs4>=0.0.2
requests>=2.32.4
urllib3>=2.5.0
```

## 2. 配置环境变量和通知

在青龙面板的环境变量中添加：

| 变量 | 说明 |
| --- | --- |
| `E_COOKIE` | 必填。建议复制浏览器请求中完整的 Cookie，必须包含值为数字的 `event` 字段。 |
| `E_PROXY` | 可选。HTTP/HTTPS 代理地址，例如 `http://127.0.0.1:8080`。 |
| `E_USER_AGENT` | 可选。自定义 User-Agent，留空使用脚本默认值。 |

登录 E-Hentai 后，可以在浏览器开发者工具的网络面板中查看请求头中的 Cookie。请妥善保管 Cookie。

旧版脚本使用青龙面板的通知模块，通知渠道通过青龙面板的通知配置设置。它不会读取单机版 `.env` 中的 `Notify` 配置。

## 3. 添加订阅和定时任务

1. 在订阅管理中添加仓库 `https://github.com/AkiyaKiko/EhentaiAutoSignIn.git`，选择 `main` 分支。原教程建议每周更新一次。
2. 将文件后缀设置为 `py`，依赖文件可填写 `notify.py`，避免拉取不需要的其他类型文件。
3. 运行订阅后，在定时任务中确认使用的是 `autosignin.py`。当前仓库也包含单机版脚本，不要将其误当作青龙任务运行。
4. 旧脚本头部的定时规则为 `1 */6 * * *`，即每天 00:01、06:01、12:01 和 18:01 运行。可在青龙面板中按需调整，并手动运行一次检查结果。

旧版检测到 Cookie 变化时只更新当前进程中的环境变量，不会自动保存到青龙面板；需要长期生效的更新请手动修改面板中的 `E_COOKIE`。
